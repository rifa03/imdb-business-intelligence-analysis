# IMDb Business Intelligence Analysis

## Project Overview

This project analyzes IMDb Top 5000 Movies dataset to identify movie trends,
genre distribution, rating performance, popularity, and audience engagement.

## Business Questions

1. What movie genres appear most frequently?
2. How does movie production trend change over years?
3. What is the relationship between IMDb rating and number of votes?
4. How are movies distributed based on rating categories?


## Dataset

Source:
IMDb Top 5000 Movies Dataset

Dataset contains:
- Movie title
- Release year
- Rating
- Number of votes
- Genre
- Directors
- Writers


## Data Preparation

Performed:
- Missing value checking
- Duplicate validation
- Outlier analysis
- Data transformation
- Feature selection


## Analysis

Tools:
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Looker Studio


## Dashboard

Dashboard provides:
- Genre distribution
- Movie trend by release year
- Rating vs votes analysis
- Rating category composition


## Key Insights

- Drama is the most frequent genre.
- Modern movies dominate the dataset.
- Higher-rated movies tend to receive more votes.
- Rating alone is insufficient to determine popularity.
